# Ball valve — 360° variant

[ball_valve_360_assembly.stl](ball_valve_360_assembly.stl) contains the base and lever in their assembled positions. It is the supplied STL export, renamed without changing the mesh.

- Import in millimetres at **100% scale**. STL has no unit metadata.
- Check the mounting-base width: **88.1 mm**. The assembled bounding box is approximately **162.3 × 76.3 × 66.1 mm**.
- Split the assembly into separate base and lever objects in the slicer, then orient each part on the print bed. Print the parts separately and assemble them afterward.

## Friction rings

[ball_valve_360_friction_ring_set.stl](ball_valve_360_friction_ring_set.stl) contains the friction rings for the 360° ball-valve variant. The supplied mesh is unchanged. Check the printed ring fit on this valve and record the ring configuration with each experiment.

See the [CAD files and assembly instructions](../../../../CAD/Valves/Ball%20Valve/Ball%20Valve%20360/) for the separate OBJ meshes, printing guidance, and experiment reporting. The standard benchmark target remains a **90° rotation**.
